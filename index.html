Background & Identity

Engineering Thinking, Applied to the Web

My background sits between engineering and design. I can discuss requirements, shape them into a usable interface, and write the code that ships it.

I'm a Multimedia Engineering graduate from Al-Azhar University, focused on front-end development. My degree combined software engineering, interaction design, and digital media, so I tend to see a product as one connected system rather than separate screens and code.

I build responsive web interfaces with React.js, JavaScript, and Tailwind CSS, usually after designing them in Figma. On full-stack projects such as TASHKHES and Market Makers, I also worked on the Node.js and Express APIs and the databases behind the interface. That experience taught me how data, authentication, and user roles shape what the front end needs to do.

How I Work

1. Analyze

I start with requirements, users, and workflows, and map them into user flows and a clear structure.

2. Design

I wireframe and prototype in Figma, focusing on hierarchy, clarity, and the feedback states users rely on.

3. Build

I turn the design into responsive, component-based code and connect it to APIs when the project needs it.
